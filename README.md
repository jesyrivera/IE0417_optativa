# Diseño de Software para Ingeniería
## IE-0417

Repositorio correspondiente al curso **IE-0417 – Diseño de Software para Ingeniería** de la **Escuela de Ingeniería Eléctrica** de la **Universidad de Costa Rica**.

## Descripción

Este repositorio contiene los laboratorios, tareas y demás actividades desarrolladas durante el curso, enfocadas en la aplicación de principios de ingeniería de software para el diseño, construcción, validación y documentación de sistemas de software.

A lo largo del curso se utilizaron herramientas modernas de desarrollo, control de versiones, pruebas de software y automatización para implementar soluciones siguiendo buenas prácticas de ingeniería.

## Contenidos

Los principales temas abordados fueron:

- Introducción a la ingeniería de software.
- Ciclo de vida del desarrollo de software.
- Modelos de desarrollo (cascada, incremental y metodologías ágiles).
- Control de versiones con Git y GitHub.
- Documentación técnica con Markdown.
- Requerimientos funcionales y no funcionales.
- Casos de uso.
- Arquitectura y diseño de software.
- Diagramas UML.
- Patrones de diseño.
- Sistemas de construcción de proyectos (CMake y Gradle).
- Refactorización y optimización de código.
- Contenedores con Docker.
- Pruebas unitarias e integración.
- Integración continua (CI/CD) mediante GitHub Actions.

## Tecnologías utilizadas
